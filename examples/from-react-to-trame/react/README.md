# from-react-to-trame

A standalone React + MUI dashboard, built without trame. It exists as a
starting point to demonstrate how a "plain React" MUI application can later be
ported to a trame app (`trame-mui` client_type="react"), widget by widget.

It showcases a broad slice of `@mui/material` and `@mui/x-charts` components
in a single, cohesive analytics dashboard: app bar, responsive navigation
drawer, KPI stat tiles with sparklines, a revenue line chart, a traffic donut
chart, a regional bar chart, a goal gauge, a paginated orders table, team
progress bars, and a preferences panel (tabs, form controls, dialogs,
accordions, snackbars).

## Run it

```bash
npm install
npm run dev
```

Then open the printed local URL (defaults to http://localhost:5175).

## Build

```bash
npm run build
npm run preview
```
